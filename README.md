# Capstone Design: PQ-C2PA-Transformer
Development of a Post-Quantum C2PA Claim Signing Framework Based on ML-DSA and SHA-3<br>
C2PA Claim 서명 알고리즘의 PQC ML-DSA 및 SHA-3 기반 전환 프레임워크 개발

## Project Goals
The goal of this project is to develop a signing and verification framework that applies ML-DSA-based digital signatures and SHA-3-based hashing to the C2PA Claim generation and validation process while maintaining compatibility with the existing C2PA structure. The development scope includes Claim data normalization, SHA-3 hash generation, ML-DSA signing and verification, public-key and certificate management, key rotation, error handling, interoperability with existing algorithms, and performance evaluation.<br>

The project will also compare conventional signing algorithms with ML-DSA in terms of signature size, signing and verification speed, key size, storage requirements, network overhead, and system scalability. Through this evaluation, the framework aims to address security threats posed by quantum computers against conventional public-key cryptography and enhance the provenance, integrity, and authenticity verification of digital content.<br>

Ultimately, the project will provide a post-quantum C2PA signing framework applicable to generative AI content, digital media, electronic documents, and software distribution environments. It is expected to contribute to the establishment of a secure, reliable, and future-proof content authentication ecosystem.<br>

C2PA Claim 생성 및 검증 과정에 ML-DSA 기반 전자서명과 SHA-3 기반 해시 함수를 적용하고, 기존 C2PA 구조와의 호환성을 고려한 서명·검증 프레임워크를 개발한다. 주요 개발 범위는 Claim 데이터 정규화, SHA-3 해시 생성, ML-DSA 서명 및 검증, 공개키 및 인증서 관리, 키 교체, 오류 처리, 기존 알고리즘과의 상호운용성 및 성능 평가 기능을 포함한다.<br>

또한 기존 서명 알고리즘과 ML-DSA를 비교하여 서명 크기, 생성 및 검증 속도, 키 크기, 저장 공간, 네트워크 오버헤드 및 시스템 확장성을 평가한다. 이를 통해 양자컴퓨터에 의한 기존 공개키 암호체계의 보안 위협에 대응하고, 디지털 콘텐츠의 출처성·무결성·진본성 검증 수준을 향상시키는 것을 목표로 한다.<br>

궁극적으로 생성형 AI 콘텐츠, 디지털 미디어, 전자문서 및 소프트웨어 배포 환경에 적용할 수 있는 양자내성 C2PA 서명 프레임워크를 제공하고, 장기적으로 안전하고 신뢰할 수 있는 콘텐츠 인증 생태계 구축에 기여한다.
